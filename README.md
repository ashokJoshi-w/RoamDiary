# 🌍 RoamDiary

<div align="center">

### ✈️ Capture Every Journey. Relive Every Memory.

RoamDiary is a modern full-stack travel journaling platform that helps travelers capture, organize, and relive their adventures. From breathtaking destinations and memorable experiences to cherished photographs, every journey is preserved in one beautiful digital diary.

## ✨ Features

### 🔐 Secure Authentication

* User Registration
* User Login
* JWT Authentication
* Protected Routes

### 📖 Travel Story Management

* Create Travel Stories
* Edit Existing Stories
* Delete Stories
* View Personal Travel Collection

### 📸 Media Uploads

* Upload Travel Images
* Image Preview Support
* Organized Media Storage

### 📍 Location Tracking

* Save Travel Destinations
* Associate Locations with Stories
* Easy Travel Organization

### 🔎 Search & Filter

* Search Travel Stories
* Quick Access to Memories
* Efficient Story Management

### 📱 Responsive Design

* Desktop Friendly
* Tablet Friendly
* Mobile Responsive
